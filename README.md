## Datasets

- `datasets/adult_classroom.csv`: Adult (US Census income), 2,000 rows.
- `datasets/bank_classroom.csv`: Bank Marketing (term-deposit subscriptions), 2,000 rows.
- `datasets/compas_classroom.csv`: COMPAS (ProPublica, Broward County recidivism), 3,000 rows.
- `datasets/german_credit_classroom.csv`: German Credit (Statlog credit risk), 1,000 rows.

Columns, labels and groups for each file: [datasets/README.md](datasets/README.md)

## Layout

- `datasets/`: the classroom CSV files and their README.
- `notebooks/`: the class Colab notebook, `fairness_lesson.ipynb`.
- `tutorials/`: the tool tutorials, published with GitHub Pages.
